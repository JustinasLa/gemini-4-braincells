Input contract, produced by part 1 in `media/screenshot.py`. Code against exactly this. Stack on part 1's branch once it is pushed. Until then, use a local copy of the dataclass and drop it when you rebase:
```python
@dataclass(frozen=True, slots=True)
class ScreenshotPost:
    media_hash: str
    platform: str            # x | bluesky | threads | facebook | instagram | tiktok | other | unknown
    display_name: str | None
    handle: str | None       # without @
    shown_time: str | None   # verbatim, e.g. "3:14 PM · Nov 13, 2026" or "2h"
    text: str | None
    counts: dict[str, int | None]   # replies, reposts, quotes, likes, views, bookmarks; None = not shown
    ui_oddities: list[str]
    confidence: float
    model: str
    latency_ms: int
```
