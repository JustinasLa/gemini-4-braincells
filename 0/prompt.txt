- One Trail per feature: from your feature branch run `entire trail create --title "<what and why>" --type feature`. Commits pushed to that branch, and the agent sessions behind them, attach to the Trail.
- Commit agent work with the agent running, so Entire links the commit to its session (`Entire-Checkpoint:` trailer). Don't amend or rebase away those trailers.

  gh pr merge <n> --squash --body "$(git log --format='%(trailers:key=Entire-Checkpoint)' origin/main..HEAD | grep . | sort -u)"

Requirements:
- tineye_url(img) = https://tineye.com/api/v1/result_json/?url=<quote(img, safe='')>&sort=crawl_date&order=asc. yandex_url(img, sites=False) = https://yandex.com/images/search?rpt=imageview&url=<enc> (+ &cbir_page=sites).
- parse_tineye: the markdown IS raw JSON (it may be wrapped in a code fence or have whitespace; be tolerant). One ImageHit per matches[] item: image_url = the earliest backlink's `url` (the copy on its own site), thumb_url = match image_url (img.tineye.com), page_url = that backlink's `backlink`, domain via sources.links.domain(page_url or image_url), first_seen = min crawl_date over its backlinks as tz-aware UTC datetime (time_source "crawl_date"), width/height, title=image_name, rank = index. NOTE TinEye's order is not strictly by date (a "promoted" 2022 Wikipedia match comes first): never assume order; min per match. total=num_matches, earliest=first_crawl_date. Raise ReverseImageError if not JSON or no matches key (an empty matches list is a valid empty result).
- parse_yandex: the imageview markdown has "## In other sizes" (links like [2560×1920](https://...jpg)) and "## [Similar images](...)" sections. Extract hits from both (view other_sizes / similar), with width/height from the "W×H" label where present, thumb from avatars.mds.yandex.net where present, absolute http(s) URLs only (resolve //host and /path relative links to https://yandex.com only for navigation, but navigation links like /images/search?... are NOT hits: skip yandex.* navigation, passport, tabbar, the query's own avatars cbir images).
